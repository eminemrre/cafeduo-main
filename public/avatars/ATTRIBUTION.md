# Curated profile avatars

These 16 SVG images are unchanged DiceBear **Pixel Art** v9 responses, downloaded
on 2026-10-02 from `https://api.dicebear.com/9.x/pixel-art/svg?seed=<filename>`.
The filenames match `AVATAR_SEEDS` in `lib/avatars.ts`.

Artist: DiceBear. License: **CC0 1.0**.

- Style and license: https://www.dicebear.com/styles/pixel-art/
- License text: https://creativecommons.org/publicdomain/zero/1.0/

Serving this catalog locally removes a third-party request from the selection
flow without adding an avatar generator to the client bundle. Keep existing
stored profile URLs unchanged; the frontend resolves curated seeds to these
files. Non-catalog legacy seeds retain their original URL and initials fallback.
